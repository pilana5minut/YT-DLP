# YouTube Playlist Audio Synchronizer

Bash-скрипт для скачивания аудиодорожек (музыка, подкасты, лекции) из любых плейлистов YouTube (включая приватные и скрытые) в формат MP3. 

## 📋 Описание и ключевые возможности

Скрипт решает проблему избыточного трафика и долгого ожидания при регулярном скачивании постоянно пополняющихся плейлистов. Вместо перезаписи всей папки, скрипт использует встроенный механизм отслеживания рание скачанных видео из прлейлиста.

*   **Умный пропуск (Интелектуальная синхронизация):** Скрипт запоминает уникальный ID каждого скачанного видео. При повторном запуске уже имеющиеся на диске элементы плейлиста мгновенно пропускаются без скачивания и траты интернет-трафика.
*   **Идеальный порядок на диске:** Скрипт автоматически организует структуру файлов прямо в папке запуска, разделяя целевые MP3-файлы и служебные логи.
*   **Авторизация через браузер:** Поддерживает скачивание приватных плейлистов за счет безопасного чтения Cookies из вашего профиля Google Chrome.
*   **Обход ограничений и стабильность:** Оптимизирован под реалии 2026 года — содержит встроенные параметры для обхода сетевого замедления YouTube (троттлинга) и автоматическое решение интерактивных JavaScript-челленджей на стороне YouTube.
*   **Безопасные имена файлов:** Принудительно очищает названия треков от запрещенных спецсимволов Linux (`?`, `*`, `:`, `(`, `)`), предотвращая ошибки файловой системы.
*   **Информативный отчет:** По окончании сеанса выводит лаконичный отчет: точное число пропущенных элементов и пронумерованный список скачанных элементов плейлиста.

## 🛠 Зависимости и предварительная настройка

Для корректной работы скрипта в системе должны быть установлены актуальные версии утилит.

### 1. Установка системных пакетов
Откройте терминал и выполните команду для установки ядра загрузчика, аудио-декодера и модуля шифрования:

```bash
sudo dnf install yt-dlp
```

```bash
sudo dnf install ffmpeg 
```

```bash
sudo dnf install python3-secretstorage
```

### 2. Установка JavaScript-движка
YouTube использует современную защиту EJS (JS-челленджи). Для их дешифровки и вычисления прямых ссылок `yt-dlp` требуется локальная среда выполнения:

```bash
sudo dnf install nodejs
```

### 3. Настройка Google Chrome
Вы должны быть физически авторизованы в своем YouTube-аккаунте через браузер Google Chrome.

## 🚀 Инструкция по запуску и использованию

Скрипт спроектирован как мобильный автономный инструмент. Его можно переносить в любую папку на жестком диске.

### Шаг 1. Создание скрипта
Поместите файл `YT-DLP.sh` в директорию, внутри которой вы хотите организовать хранение музыки (например, `~/Downloads/Favorites` или отдельно созданную папку).

### Шаг 2. Предоставление прав на запуск
Сделайте файл исполняемым. Откройте терминал в папке со скриптом и выполните:
```bash
chmod +x YT-DLP.sh
```

### Шаг 3. Запуск скачивания
Скрипт принимает ссылку на плейлист в качестве аргумента. Запустите его, обязательно обернув ссылку в двойные кавычки `""` (чтобы спецсимволы YouTube вроде `&` или `?` не перехватывались интерпретатором Bash):

```bash
./YT-DLP.sh "https://www.youtube.com/playlist?list=PLCueFkwRzmjA"
```

## 📂 Структура каталогов после работы

Скрипт исключает появление бардака в рабочей директории. После первого запуска структура файлов примет следующий вид:

```text
📂 Папка_запуска_скрипта/
├── 📄 YT-DLP.sh                   # Исполняемый скрипт
├── 📂 Music_Files/                # Сюда складываются готовые аудиофайлы
│   ├── 🎵 Track_Name_1_[ID].mp3
│   └── 🎵 Track_Name_2_[ID].mp3
└── 📂 Service_Files/              # Изолированная папка для служебных данных
    ├── 📝 downloaded_songs.txt    # База данных скачанных ID YouTube
    └── 📝 sync_log.txt            # Технический лог текущего сеанса
```

## 🧠 Принцип работы и нюансы автоматизации

1.  **Как работает пропуск видео:** Внутри папки `Service_Files` создается текстовый файл `downloaded_songs.txt`. Каждый раз, когда элемент плейлиста успешно конвертируется в MP3, `yt-dlp` дописывает в него строчку формата `youtube <ID_видео>`. При повторном старте скрипт сопоставляет ID видео из плейлиста с этим списком. Если совпадение найдено, элемент пропускается за миллисекунды.
2.  **Служебный лог (`sync_log.txt`):** Файл технического лога автоматически перезаписывается (очищается до нуля) при каждом новом старте скрипта. Вы можете безопасно удалять его вручную в любой момент. Файл же `downloaded_songs.txt` удалять **нельзя**, иначе история загрузок сотрется и начнется полное повторное скачивание файлов.
3.  **Математическая точность отчета:** Скрипт не полагается на текстовый поток терминала, который может склеиваться при сетевых сбоях. Он фиксирует количество строк в файле архива до начала скачивания и после него, вычисляя разницу. Это гарантирует 100% точность вывода итоговых счетчиков.
